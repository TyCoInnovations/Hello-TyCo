# Welcome to Hello TyCo!
This is our public repository that acts as a wiki, support page, donation page, and issues/improvements logging page all in one! This is for all users who want to help out TyCo with making great things. Whether that's contributing code, or a small donation!
If you look at the top of your screen, you'll see a bunch of tabs. Code, Issues, Discussions, and Wiki. Each of those does a different thing, lets start with
## Code
What you're already on (i'm assuming). It acts like a homepage, that allows you to donate, see our website and support email, and more. It doesn't do everything though.
## Issues
Issues allows you to report bugs and suggest improvements to our code. As long as you have a GitHub account, you can add an issue and we'll look into it! We'll make sure to keep you updated as well.
## Discussions
Discussions allows you to send us messages directly, whether it's asking for support, or chatting with the community. It's also used to post announcements about products, or just stuff about TyCo.
## Wiki
Wiki is the instruction manual to all TyCo Products, it allows you to see what the product does, and every feature and use case it provides.
